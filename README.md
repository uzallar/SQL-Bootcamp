# SQL Bootcamp Portfolio

Здесь собраны небольшие проекты по SQL.

## Структура репозитория

- SQL_Day00 ... SQL_Day09: ежедневные блоки задач
- SQL_Team00, SQL_Team01: командные проектные задания
- Внутри каждого дня:
	- README.md с постановкой задач
	- materials/model.sql со схемой и тестовыми данными
	- src/ с решениями

## Технический стек

- СУБД: PostgreSQL
- Инструменты: psql, pgAdmin
- Работа с данными: JOIN, CTE, subqueries, set operations, window functions
- Надежность: транзакции, уровни изоляции, контроль целостности
- Производительность: индексы, материализованные представления, оптимизация запросов
- Data Engineering практики: ETL
- Git, GitHub

## Что реализовано

- SELECT-запросы, фильтрация, сортировка, работа с NULL
- JOIN, подзапросы, CTE, операции над множествами
- DML-операции: INSERT, UPDATE, DELETE
- Транзакции и уровни изоляции
- Оконные функции и аналитические выборки
- Индексы, материализованные представления, оптимизация запросов
- ETL-подход
- Алгоритмические задачи на SQL

## Как запустить локально

1. Установить PostgreSQL (рекомендуется актуальная версия 14+).
2. Создать локальную БД, например sql_bootcamp.
3. Выбрать нужный день и развернуть модель из materials/model.sql.
4. Запускать SQL-скрипты из src/ через psql, DataGrip или pgAdmin.
